A daily tracker of proxy clients built on mihomo, sing-box, Xray, V2Ray, Clash and their own cores. Open-source projects are measured by GitHub stars, store apps by US App Store / Google Play rating counts.

**Data as of: 2026-10-18** · [Web version (filters and sorting)](https://clientsradar.com/)

## Fast-rising

- **[Bettbox](https://github.com/appshubcc/Bettbox)** · High growth, Newcomer — New in Nov 2025; covers HarmonyOS and TV. Stars grew about 90% in the last 90 days
- **[ClashBar](https://github.com/Sitoi/ClashBar)** · High growth, Newcomer — Growth slowed this week. Native menu-bar app, new in Feb 2026; up 13% in 30 days
- **[Satelite Proxy](https://github.com/zn0wii/satelite-proxy)** · High growth, Newcomer — Growth slowed this week. A Rust desktop client created in August with switchable sing-box / Xray / mihomo cores, Clash subscription import and TUN
- **[Clash Mi](https://apps.apple.com/us/app/id6744321968)** (App Store) · Fast growth — Ratings up 7.4% in 7 days. Free mihomo client for iOS from the Karing team

- **[sing-box MT](https://apps.apple.com/us/app/id6785326793)** (App Store) · New release — Listed in August 2026; updated to 1.14.7 on October 9. The store version the official sing-box docs now point to; the old sing-box VT is no longer listed
